# The repository is public; personal data never enters it

Vela's source is public on GitHub. Everything personal stays out of the repository: tailnet hostnames, the Pyxis device token, saved places, home and work addresses, listening history and real cover art. Mockups and tests use invented or openly licensed content.

## Consequences

- Service origins, the tailnet name and the Valhalla URL are set where Vela is installed, in the mountainous flake. They are never constants in Vela's code.
- The explorations in the private exploration folder hold real covers and real library titles, so they must not be copied into the repository as they are.
